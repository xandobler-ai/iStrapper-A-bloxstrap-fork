# iStrapper 🚀

Advanced Roblox bootstrapper with mod support, FPS unlocker, and iOS compatibility.

## ✨ Features

- **🎨 Mod System**: Fonts, Scripts, Textures
- **🎮 FPS Unlocker**: Custom FPS limits (30-360)
- **📱 iOS Compatibility**: Touch controls, mobile UI
- **📦 GitHub Integration**: Auto-updates
- **💉 DLL Injection**: Custom DLL support
- **🖥️ Graphics Settings**: Quality presets

## 🚀 Usage

1. Place mods in the Mods folder
2. Launch iStrapper
3. Apply mods
4. Launch Roblox

## 🔧 Building

dotnet build -c Release
